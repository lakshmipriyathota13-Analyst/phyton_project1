# 🐍 Python Mini-project

This repository contains solutions to Python practice problems designed to strengthen programming logic and problem-solving skills.  
All programs are organized topic-wise for clarity and easy navigation.

---

## 📂 Repository Structure
│
├── 01_Basic_Python
├── 02_Decision_Making
├── 03_Loops
├── 04_Lists
├── 05_Dictionaries
├── 06_Tuples
├── 07_Sets
└── 08_Functions


Each folder contains Python scripts (`.py` files) with meaningful filenames corresponding to the  questions.

---

## 📘 Topics Covered

### 1. Basic Python
- Printing output
- Variables and data types
- Arithmetic operations
- Area calculations
- Temperature conversion
- Swapping values

### 2. Decision-Making
- If, if-else, if-elif-else statements
- Positive/negative, even/odd checks
- Voting eligibility
- Grading system
- Leap year check
- Menu-driven programs (Calculator, Banking, Student Info, Conversions)

### 3. Loops
- For and while loops
- Number sequences
- Multiplication tables
- Factorials
- Sums of ranges
- Divisibility checks

### 4. Lists
- Length, sum, max, min
- Sorting
- Counting pass/fail students
- Average marks
- Filtering even/odd numbers
- Creating sublists

### 5. Dictionaries
- Keys and values
- Adding/updating/removing entries
- Student and product data
- Highest marks/salaries
- Total values

### 6. Tuples
- Indexing
- Length, sum, max, min
- Membership checks
- Count and index functions

### 7. Sets
- Creating sets
- Union, intersection, difference
- Membership checks
- Handling duplicates
- Comparing student sets

### 8. Functions
- Basic functions (sum, square, factorial, grade check)
- Functions with lists (length, sum, filtering)
- Functions with dictionaries (highest marks, total price)
